## 🚀 How to Use the Improvements

1. **Start Backend**
   ```bash
   cd BackEnd
   npm install
   node server.js
   ```

2. **Start Frontend**
   ```bash
   cd Frontend
   npm install
   npm run dev
   ```

3. **Open Browser**
   - Navigate to `http://localhost:5173`

4. **Use Advanced Features**
   - Select language from dropdown
   - View code statistics
   - Toggle theme
   - Get AI review
   - Copy results
